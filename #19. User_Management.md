# User Management in Linux

## Why User Management?

Linux is a **multi-user system** - multiple users can work on the same machine simultaneously. Proper user management ensures that each user has appropriate access, their own workspace, and that the system remains secure and organized.


## Creating a New User

### Basic User Creation

```bash
sudo useradd dev1
```

- Creates a new user named `dev1`.
- Requires `sudo` (admin privileges).
- **Note:** This does NOT create a home directory for the user by default.

### Set Password for the User

```bash
sudo passwd dev1
```

- Prompts you to enter and confirm a password for the `dev1` user.


---


## Creating a User with Home Directory

```bash
sudo useradd -m dev2
```

- The `-m` flag creates a **home directory** at `/home/dev2` along with the user.
- Without `-m`, the user exists but has no dedicated home directory.

```bash
sudo passwd dev2
```


---


## Viewing User Details

### Check User Information

```bash
id dev1
```

- Displays the **user ID (uid)**, **group ID (gid)**, and all **groups** the user belongs to.

### List All Users on the System

```bash
cat /etc/passwd
```

- The `/etc/passwd` file contains details of **every user** on the system.
- Shows default users (like `ubuntu`) and any newly created users.


---


## Switching Between Users

### Switch to Another User

```bash
su - dev2
```

- Switches to the `dev2` user session.
- Prompts for the user's password.
- The `-` flag loads the user's environment and places you in their home directory.

### Verify Current User

```bash
whoami
```

- Outputs the name of the currently logged-in user.

### Check Current Working Directory

```bash
pwd
```

- After switching to `dev2`, this shows `/home/dev2`.


---


## Home Directory Behavior

- Each user with a home directory has a **private workspace** at `/home/<username>`.
- All files and directories created by a user are stored within their home directory.
- Listing the `/home` directory shows all user home directories:

```bash
ls /home
# Output: dev2  ubuntu
```

- Only users created with `-m` (or manually configured) will have a home directory here.


---


## Default Group Assignment

When a new user is created, Linux **automatically creates a group with the same name** as the user and assigns the user to it.

```bash
id dev1
# uid=1001(dev1) gid=1001(dev1) groups=1001(dev1)
```

- `dev1` is part of the `dev1` group by default.
- Users can also be added to additional groups (covered in Group Management).


---


## Deleting a User

```bash
sudo userdel dev1
```

- Removes the user `dev1` from the system.
- After deletion, the user no longer exists:

```bash
id dev1
# Output: id: 'dev1': no such user
```


---


## Quick Reference

| Command                  | Description                                  |
|--------------------------|----------------------------------------------|
| `sudo useradd dev1`     | Create a new user (without home directory)   |
| `sudo useradd -m dev2`  | Create a new user with home directory        |
| `sudo passwd dev1`      | Set or change password for a user            |
| `id dev1`               | Display user ID, group ID, and groups        |
| `cat /etc/passwd`       | List all users on the system                 |
| `su - dev2`             | Switch to another user                       |
| `whoami`                | Show currently logged-in user                |
| `sudo userdel dev1`     | Delete a user                                |


---


## Summary

- Use `sudo useradd` to create users — add `-m` to include a home directory.
- Each user gets a **default group** with the same name automatically.
- Use `su - <username>` to switch between users and `whoami` to check the current user.
- The `/etc/passwd` file stores information about all system users.
- Use `sudo userdel` to remove a user when no longer needed.
